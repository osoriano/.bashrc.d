# Install Guide

## Ubuntu
1. Install or clone this directory into `~/gh/osoriano/.bashrc.d`

2. Include `source ~/gh/osoriano/.bashrc.d/bashrc.sh` in `~/.bashrc`

3. Include `source ~/gh/osoriano/.bashrc.d/profile.sh` in `~/.profile` or `~/.bash_profile`

## Mac
1. Install or clone this directory into `~/gh/osoriano/.bashrc.d`

2. Include `source ~/gh/osoriano/.bashrc.d/bashrc.sh` and `source ~/gh/osoriano/.bashrc.d/profile.sh` in `~/.bash_profile`

Enjoy!
